# CPU Emulator

Программный эмулятор простого 32-битного процессора, реализованный на C++.

Проект позволяет загружать и выполнять программы на собственном упрощённом языке ассемблера, отслеживать состояние процессора после каждой инструкции и изучать принципы работы основных компонентов CPU.

## Возможности

- Эмуляция 32-битного процессора.
- 8 регистров общего назначения (R1–R8).
- Оперативная память объёмом 4 КБ.
- 48-битный формат машинной инструкции.
- Поддержка прямой, косвенной, регистровой и непосредственной адресации.
- Поддержка арифметических операций и флагов процессора.
- Условные переходы.
- Загрузка программ из файлов `.asm`.
- Вывод состояния процессора после каждой выполненной инструкции.

## Архитектура процессора

| Компонент | Характеристика |
|---|---|
| Архитектура | Фон Неймана |
| Разрядность данных | 32 бита |
| Регистры общего назначения | 8 × 32 бита |
| PC | 16 бит |
| IR | 48 бит |
| RF | 8 бит |
| Оперативная память | 4096 байт |
| Длина инструкции | 6 байт |
| Порядок байтов | Little-endian |

Память разделена на две логические области:

- Адреса 0–2047 — область программ.
- Адреса 2048–4095 — область данных.

## Система команд

| Команда | Назначение |
|---|---|
| `LOAD` | Загрузка значения из памяти в регистр |
| `MOV` | Запись непосредственного значения или адреса в регистр |
| `ADD` | Сложение |
| `SUB` | Вычитание |
| `ADC` | Сложение с учётом флага переноса |
| `MUL` | Умножение двух знаковых 32-битных чисел |
| `JNZ` | Переход, если флаг нуля не установлен |
| `HALT` | Остановка процессора |

## Компиляция

Для сборки проекта необходим компилятор с поддержкой C++17 или новее.

Откройте терминал в корневой директории проекта и запустите автоматическую сборку выполнив команду make.

После успешной компиляции будет создан исполняемый файл:

- `.\appendix\cpu_emulator.exe`

## Запуск

```powershell
.\cpu_emulator.exe
```

## Работа с программой

После запуска эмулятор запрашивает путь к файлу с исходным кодом программы на ассемблере.

Укажите путь до файла, например:

```text
.\Asm_code\sum_arr.asm
```

После загрузки и обработки исходного кода начинается выполнение программы.

В процессе выполнения после каждой инструкции отображается состояние процессора:

- PC — адрес следующей инструкции.
- IR — текущая машинная инструкция.
- R1–R8 — содержимое регистров общего назначения.
- RF — регистр флагов.
- HALTED — состояние процессора.

После выполнения команды `HALT` программа завершает эмуляцию.

## Написание программ на ассемблере

Исходный код программы состоит из двух основных секций:

- `.data` — объявление данных.
- `.text` — последовательность инструкций процессора.

### Пример программы

```asm
.data

A: 10, 5, 12, -3, 8, 15, -7, 2, 10, -4, 6

.text

LOAD R1, [A]
MOV R2, A
MOV R4, 0

M1:
ADD R2, 4
LOAD R3, [R2]
ADD R4, R3
SUB R1, 1
JNZ M1

HALT
```

В данном примере первый элемент массива содержит количество обрабатываемых элементов. 
Остальные значения последовательно загружаются из памяти и суммируются.

После завершения программы в регистре R4 будет находиться результат вычисления — `44`.

### Объявление данных

Данные объявляются в формате:

```asm
.data

array: 10, 5, 12, -3, 8
```

Каждое значение массива занимает 4 байта и представляется знаковым 32-битным целым числом.

Объявление массива должно располагаться на одной строке.

### Метки

Метки используются для обозначения адресов инструкций и данных.

Пример:

```asm
.text

START:
MOV R1, 10
```

Для перехода к метке используется соответствующая команда:

```asm
JNZ START
```

### Комментарии

Для добавления комментариев используется символ `;`.

```asm
MOV R1, 10 ; Записываем значение 10 в R1
```

## Примечания

- Нумерация регистров в ассемблере начинается с R1.
- Адресация памяти побайтовая.
- Размер каждого элемента данных — 4 байта.
- Все инструкции имеют фиксированную длину 6 байт.
- Числа со знаком представлены в дополнительном коде.
- Для корректного завершения программы необходимо использовать команду `HALT`.

## Пример использования

В качестве проверки корректности работы эмулятора реализована программа вычисления скалярного произведения двух массивов (sum_mul_arr.asm).

Результат вычисления:

```text
3275
```

Результат программы выводится в файл log[i].txt, где i это номер запуска одного ассемблерного кода.
Программа проверяет работу загрузки данных, арифметических операций, умножения, переноса, условных переходов и счётчика цикла.
